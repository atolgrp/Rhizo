# Project instructions

Read **[PROMPT.md](PROMPT.md)** before doing anything else — it is the standing
brief for this project and states the goal, the decisions already taken and why,
and what has been verified empirically.

Then **[PLAN.md](PLAN.md)** for the current phase and its validation gate.

Two things that are easy to get wrong here:

1. **The discretisation question is still open** (PLAN.md Phase 0). Do not write
   physics on top of an assumption about it.
2. **Mass balance is a pass/fail criterion, not a diagnostic.** Report it for
   every transport run.
